# Source R files into environment

Source R files into environment

## Usage

``` r
source_to_environment(
  proj,
  env,
  folders_to_be_sourced,
  source_folders_absolute
)
```

## Arguments

- proj:

  Project environment

- env:

  Target environment for sourcing

- folders_to_be_sourced:

  Folders containing R files

- source_folders_absolute:

  Whether folder paths are absolute
