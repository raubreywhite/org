# Initialize project folder structure

Initialize project folder structure

## Usage

``` r
initialize_project_folders(
  env,
  home,
  results,
  encode_from,
  encode_to,
  proj,
  ...
)
```

## Arguments

- env:

  Environment to source code into.

- home:

  Home directory path.

- results:

  Results directory path.

- encode_from:

  Source encoding.

- encode_to:

  Target encoding.

- proj:

  Project environment.

- ...:

  Additional folder arguments.
